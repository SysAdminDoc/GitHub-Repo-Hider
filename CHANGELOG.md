# Changelog

## [0.0.2] - 2026-10-10

- Hiding or unhiding a repo no longer pops up a message. The row just goes away. Clear all in the manager still offers Undo.
- Fixed rows that loaded slowly ending up with a hover-only eye icon instead of the Hide button next to Star. The button now moves into place as soon as the Star column shows up.

## [0.0.1] - 2026-10-10

- First release.
- Hide button next to Star on your Repositories and Stars tabs, plus a hover button on pinned and popular cards.
- Hidden repos also drop out of the dashboard's Top repositories sidebar and the navigation side panel.
- Corner pill with a count of hidden repos on the page, a Show toggle that brings them back dimmed, and a link to the manager.
- Manager for pasting repos to hide (names, links or whole lists), unhiding, copying the list and clearing it.
- The list syncs live between open GitHub tabs.
